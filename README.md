# HALCYON: Five Nights at the Aviary

A browser game. Play it here, on any phone, tablet, or computer:

https://halcyon-x5rpp9ggpwqgf96jq-8077.app.github.dev

The Codespace sleeps after 4 hours with nobody using it. If the page says it is stopped, open https://github.com/codespaces, start HALCYON, and use the link again. Every device that uses this link shares one save.

The game server starts on its own when the Codespace starts. Progress is stored on that server, so every device that uses the same link continues the same game.

## Play on this computer

```
python server.py
```

Then open http://127.0.0.1:8077/
